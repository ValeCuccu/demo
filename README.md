# Terminal Portfolio Demo

Demo interattiva del portfolio di Valentino Cuccu in stile terminale.

## Comandi

- help
- about
- projects
- skills
- cv
- contact
- whoami
- pwd
- ls
- clear

Sono supportati anche TAB per l'autocompletamento e le frecce ↑/↓ per la cronologia.

Questa repository è una demo temporanea per testare il concept prima di costruire la versione definitiva.
